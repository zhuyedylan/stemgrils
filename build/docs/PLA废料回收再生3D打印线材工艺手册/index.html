# PLA废料回收再生3D打印线材工艺手册

# 宁逸可

一、材料来源与选择

1 目标材料

聚乳酸（PLA），一种生物基可降解聚酯，熔融温度适中、打印气味小、易于加工。

2 常见来源

· 废弃的PLA 3D打印失败品、支撑结构、废料

· PLA咖啡杯、透明餐盒等一次性餐具（需确认材质标识）

· 过期或废弃的PLA线材卷

3 选择理由

PLA玻璃化转变温度约60℃，熔融温度160–210℃，热稳定性较好，加工过程中无明显有毒气体释放，适合在校园或家庭环境下通过小型设备进行熔融再生。

注意：仅限使用明确标识为PLA的塑料。避免混入PET、ABS、PVC等其他种类塑料，否则会导致堵头或性能劣化。

四、实操步骤详解

第一阶段：废料预处理

  1. 分拣与清洗

    剔除标签、胶水、纸质部分。用清水洗去油污、食物残渣，自然晾干或擦干。

  2. 破碎

    使用小型粉碎机将废PLA打碎。必须盖死盖子再开机，运转时手绝对不可伸入。

    目标粒径：自产废料7–10mm，外来废料3–6mm。建议连续粉碎2–3次，并过筛分级。

  3. 烘干

    PLA易吸潮，水分会导致挤出的线材布满气泡、变脆。

    将颗粒放入干燥箱或线材干燥盒，80℃烘2小时（或60℃烘4小时），确保水分指标尽可能低（理想<0.02%）。

第二阶段：熔融挤出制丝

  1. 开机预热

    打开挤出机电源，设定熔融温度至175℃，待温度稳定。

  2. 加料

    将干燥后的PLA颗粒缓慢加入料斗。注意不要一次加满，保持匀速进料。

  3. 挤出与牵引

    · 当熔融物料从模头流出后，用镊子引导线材穿过风冷通道，再引入牵引机。

    · 启动牵引机和收卷机，调节牵引速度使线径稳定在1.75±0.05mm。

    · 实时用游标卡尺测量线径，动态微调牵引速度。

  4. 风冷

    确保风扇或风道对准挤出线材，实现梯度降温。不可使用水冷，否则PLA会因急冷而开裂或产生内应力。

第三阶段：卷绕与检测

  1. 线材经过牵引后均匀收卷在线盘上，避免交叉堆叠。

  2. 每卷线材至少取5个不同位置测量直径，记录最大值、最小值。

  3. 检查表面是否有气泡、颗粒、划痕。不合格段应剪除。

第四阶段：打印验证与救场

  1. 将自制线材装入3D打印机，先打印20mm校准立方体，观察首层附着、层间结合、表面质量。

  2. 若打印正常，再尝试打印功能件（如铰链、齿轮）。

突发情况：堵头怎么办？

如果线材在喷嘴内卡死（因杂质或焦化物），切勿用尖锐物硬捅。使用冷拉法：

· 将喷嘴加热至约160℃（PLA软化但未完全熔融）。

· 捏住线材，猛地向外拔，可将堵在喷嘴内的焦化物连根拔出。

· 清理后剪去变形段，重新进料即可。

五、安全须知

必须遵守的安全规则

  1. 防烫手套

    挤出机、干燥箱、喷嘴工作时温度高达200℃。需要靠近出料口或更换模头时，必须佩戴厚实防烫手套。

  2. 粉碎机安全

    使用粉碎机时，盖紧盖子再开机。机器运转期间，手绝对不准伸入！用推料棒辅助进料。

  3. 水电分离

    设备远离水池。手未擦干时，禁止触碰任何电源开关或插座。

  4. 通风

    PLA加工时虽无明显毒气，但仍建议在通风良好处操作，避免长时间吸入热塑料释放的微量气体。

  5. 个人防护

    建议佩戴口罩、护目镜，防止破碎时飞溅的塑料屑伤人。

七、经验总结与优化建议

7.1 成功关键

· 干燥优先：PLA含水量直接影响线材质量，宁可多烘半小时。

· 风冷替代水冷：PLA低温慢冷才能保持韧性，急冷必脆。

· 数据驱动调试：记录每次温度、转速、牵引速度与线径，建立参数表。

· 先简后繁：先打校准立方体，再打复杂模型，逐步验证。

7.2 设备改进方向

· 加装在线测径仪，实现闭环反馈控制。

· 使用可换模头，适配不同直径（1.75mm / 2.85mm）。

· 设计一体化破碎-挤出-卷绕小型设备，降低操作门槛。

7.3 材料扩展

· 尝试PLA+PBAT共混改性，提升柔韧性。

· 探索添加咖啡渣（3%比例）、木粉等天然填料，制作复合线材。

八、总结

本手册验证了利用小型单螺杆挤出机，将废旧PLA制品再生为合格3D打印线材的可行性。通过分拣→破碎→烘干→风冷挤出→线径检测→打印验证的标准化流程，可获得直径1.75±0.05mm、表面光滑、打印流畅的自制线材。这一方案为校园、家庭场景下实现塑料闭环循环提供了安全、可操作的实践指南，兼具环保教育与STEM创新价值
