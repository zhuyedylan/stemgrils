<a id="heading_3"></a>__主题：塑·缚——从蓝色星球到塑料星球__

<a id="heading_4"></a>__核心内容__

- 全球塑料年产量超__4亿吨__，40%为一次性包装

- 每分钟1辆垃圾车塑料入海，年超500万辆

- 塑料瓶降解需__450年__，钓鱼线达__600年__

- 微塑料沿食物链富集，人类每周摄入约5克（相当于1张信用卡）

- 超700种海洋生物受塑料污染危害

<a id="heading_5"></a>__行动倡议__

拒绝一次性塑料、重复使用、正确回收、参与净滩

__口号__：没有扔掉的塑料，只有被错置的资源

<a id="heading_6"></a>__二、再生3D打印技术原理（Word打印适配：段落首行缩进2字符，行距1\.5倍）__

再生3D打印是__废旧塑料回收再生__与__FDM熔融沉积3D打印__相结合的绿色增材制造技术。

- 核心逻辑：不破坏塑料分子结构，通过物理回收→熔融→挤出制丝→3D打印，实现“垃圾→资源→产品”闭环

- 适用材料：PLA、PP、ABS、PET等干净单一塑料

- 优势：家庭/校园可操作、低碳环保、可定制化文创与实用制品

<a id="heading_7"></a>__三、废旧塑料材料分类回收指南（Word打印适配：段落首行缩进2字符，行距1\.5倍）__

<a id="heading_8"></a>__1\. 常见可回收塑料__

- __PET__：矿泉水瓶、塑料盒（熔点250\-265℃，加工温度260\-280℃）

- __PP__：瓶盖、保鲜盒、水盆（熔点164\-170℃，加工温度170\-200℃）

- __PLA__：可降解餐盒、环保吸管（生物基可降解，熔点150\-180℃，加工温度160\-195℃）

- __ABS__：玩具、家电外壳、乐高（熔点/加工温度210\-240℃）

<a id="heading_9"></a>__2\. 回收三原则__

1. __单一分类__：不同塑料严禁混合

2. __彻底清洁__：无油污、无贴纸、无食物残留

3. __充分干燥__：水分是线材气泡、脆断主因

<a id="heading_10"></a>__3\. 趣味分类（猪猪分类法）__

- 可以食用：PLA/PBAT可降解塑料

- 不可食用：受污染普通塑料

- 具备毒性：农药/化工残留塑料

- 可换零食：干净PET/PP/PS/ABS

<a id="heading_14"></a>__六、核心再生工艺介绍（Word打印适配：段落首行缩进2字符，行距1\.5倍，每个工艺单独成段，便于阅读）__

<a id="heading_15"></a>__工艺1：废旧PET棉花糖仿丝工艺（田苏佳）__

- 材料：干净PET瓶/盒剪碎（0\.5cm）

- 温度：260\-280℃

- 设备：棉花糖机\+风扇冷却

- 要点：少量多次加料、中强风冷却、中高速离心

- 用途：装饰、填充、隔音保温棉

<a id="heading_16"></a>__工艺2：PP瓶盖\+纯PP再生3D打印线材（吴采晞）__

- 配比：瓶盖碎料:纯PP=3:7

- 挤出温度：200℃

- 线材直径：1\.75mm±0\.05mm

- 打印：喷嘴240℃、热床100℃

- 成品：彩色环保笔筒

<a id="heading_17"></a>__工艺3：PLA\+咖啡渣再生3D打印线材（朱可人）__

- 黄金配比：咖啡渣:PLA=3:97

- 烘干：咖啡渣100℃/8h；PLA80℃/8h

- 挤出：180\-195℃

- 打印：大口径喷嘴（≥0\.5mm）、硬化钢喷嘴

- 特色：天然咖啡香、岩石磨砂质感

<a id="heading_18"></a>__工艺4：废旧PLA纯料再生3D打印线材（宁逸可）__

- 挤出温度：175℃（最佳）

- 冷却：__风冷禁水冷__（防脆裂）

- 线材：1\.75mm±0\.05mm

- 打印：喷嘴190\-210℃、热床40\-60℃

<a id="heading_19"></a>__工艺5：废旧ABS再生3D打印线材（王佳艺）__

- 烘干：100℃/4h

- 挤出温度：205℃

- 打印：喷嘴250℃、热床60℃

- 特点：强度高、抗摔、适合结构件

__工艺6：废旧PET塑料瓶拉丝再生3D打印线材（袁其乐、李雪睿）__

- 烘干：350℃/热风枪

- 设备：桌面型裁切拉丝装置

- 裁切：将塑料瓶分割为8mm宽均匀长条

- 拉丝：温度240℃左右，孔径1\.75mm

- 打印：喷嘴250℃、热床60℃

- 特点：简易、便捷

<a id="heading_20"></a>__七、安全操作规范（Word打印适配：段落首行缩进2字符，行距1\.5倍）__

1. 全程通风，佩戴口罩、护目镜、耐热手套

2. 高温部件严禁徒手触碰，防烫防烫伤

3. 粉碎/挤出设备运转时手不伸入，卡料先断电

4. 水电分离，设备接地良好

5. 仅限单一干净塑料，禁混PVC等有毒材料

6. 设备连续工作限时，防止过热降解

7. “未成年人必须在老师或受过专业培训的成人指导下进行设备操作”。
